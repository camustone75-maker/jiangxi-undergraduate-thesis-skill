# 手册来源映射

本 Skill 根据工作区中的《2026届普通本科毕业论文（设计）指导手册》整理。需要回看原文或处理学院最新模板时，按以下页码定位：

- 第 1 页：目录；
- 第 6—15 页：普通本科毕业论文（设计）工作管理办法，包括选题、开题、中期检查、指导、检测、评阅和答辩流程；
- 第 16—26 页：普通本科毕业论文（设计）写作规范，包括字数、摘要、正文、文献综述、参考文献、公式、图表、页码、纸张和材料归档；
- 第 27—38 页：规范样式，包括封面、诚信承诺书、中文摘要、英文摘要、目录、正文层级、表格、图片、公式、参考文献和附录；
- 第 40—42 页：选题方向审核表、选题方向指南和选题汇总表；
- 第 43—46 页：文献综述写作要求及文献综述样式；
- 第 47—56 页：开题报告、任务书、工作中期检查表、指导情况登记表、指导教师评阅表、评阅教师评阅表、答辩委员会评定表和答辩记录；
- 第 57—58 页：统计表、成绩汇总表和优秀毕业论文（设计）申请表。

页码指 PDF 页码。若学院发布新版本，优先以新版本为准，并更新本文件和 `format-spec.md` 中受影响的条目。
