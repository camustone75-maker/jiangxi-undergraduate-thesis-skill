# 本科毕业论文工作检查清单

## 选题与开题

- [ ] 题目不超过通常建议的 20 个汉字，研究对象、问题和范围明确。
- [ ] 题目与专业方向、现实问题和可取得的数据相匹配。
- [ ] 已明确研究目的与意义、主要研究内容、研究方法、资料来源和时间安排。
- [ ] 已准备选题方向审核表、开题报告及任务书所需字段。

## 文献综述与研究设计

- [ ] 文献综述围绕主题综合归纳，而非逐篇罗列。
- [ ] 一般综述不少于 15 篇参考文献、至少 3 篇外文文献、正文不少于 2000 字。
- [ ] 毕业论文参考文献总体不少于 20 篇、至少 2 篇外文文献，且与研究问题直接相关。
- [ ] 研究问题、变量或分析维度、数据来源和研究方法彼此对应。

## 正文内容

- [ ] 正文字数达到 8000 字以上（不含图表、程序和计算数字）。
- [ ] 引言交代背景、意义、研究现状或综述、研究思路和结构。
- [ ] 主体章节有清晰层级，论点有数据、文献或案例证据支持。
- [ ] 结论回应研究问题，并说明不足与后续研究方向。
- [ ] 所有数据、图表、外部观点和直接引用均有来源。

## 排版与引用

- [ ] A4 纸，版心、页眉、页脚、页码和装订设置符合学院模板。
- [ ] 正文小四号宋体，固定行距 22 磅；英文和数字使用 Times New Roman。
- [ ] 标题采用 1、1.1、1.1.1 层级，不混用中文章节编号。
- [ ] 表题在表上方、图题在图下方，编号按章节连续；表格优先使用三线表。
- [ ] 公式单独成行，编号位于右侧括号中，编号不使用点线连接。
- [ ] 目录标题、页码与正文实际内容一致，优先使用自动目录。
- [ ] 参考文献按 GB/T 7714—2015 编排，并逐条核对正文引用。

## 规范与提交

- [ ] 已完成重复率检测，并按照学院要求处理超标内容。
- [ ] 指导教师已完成规定次数的指导和评阅环节。
- [ ] 已准备中期检查、指导情况登记、评阅、答辩记录和答辩委员会评定材料。
- [ ] 论文正文和附件文件命名符合“学院—学号—姓名”等学院命名要求。
- [ ] Word、PDF 和附件版本内容一致，打开后无缺图、缺表、乱码、空白页或页码错误。
- [ ] 最终提交前保留可编辑源文件和提交版 PDF，避免只保存截图或扫描件。
