# 江西省大学生本科论文规范 Skill

一个供 Codex 使用的 Skill，帮助普通本科生按论文指导手册整理选题、开题、论文结构、格式、参考文献和答辩材料。

## 安装

将 `jiangxi-undergraduate-thesis` 文件夹放入 Codex 的 skills 目录，然后在对话中输入 `$jiangxi-undergraduate-thesis` 调用。

## 文件

- `SKILL.md`：技能说明和工作流程。
- `references/format-spec.md`：格式与写作要求摘要。
- `references/workflow-checklist.md`：论文工作检查清单。
- `references/source-map.md`：对应指导手册的章节和页码索引。
- `agents/openai.yaml`：Codex 界面显示信息。

## 适用范围

内容依据《2026届普通本科毕业论文（设计）指导手册》整理，属于便于使用的规范摘要，不是学院官方文件，也不替代学院或指导教师提供的最新要求。手册及要求可能更新，使用前应核对最新模板。

此 Skill 用于辅助研究和写作流程，不应被用于伪造数据、虚构引文、抄袭或代替学生独立完成论文。
